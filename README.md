# Genial Matura Webshop

Statische HTML/CSS/JavaScript-Website für die Übung „Webshop für ein Start-up".

## Projektidee

**Genial Matura** ist eine fiktive interaktive Matura-Vorbereitungsplattform. Das Produkt bietet digitale Übungen, Quizfunktionen, Schritt-für-Schritt-Erklärungen, Fortschrittsanzeigen, Matura-Simulationen und Lernpakete für verschiedene Maturafächer.

## Unternehmen

- Unternehmensname: Genial Learning e.U.
- Standort: Wien, Österreich
- Mitarbeiter:innen: 5
- Geschäftsmodell: Freemium, Pro-Abo, Einmalverkauf von Matura-Paketen und optionale Schullizenzen

## Umsetzung

Die Website ist statisch umgesetzt. Warenkorb, Checkout, Kontaktformular, Cookie-Einstellungen und Analyseprozesse sind nur simuliert. Es werden keine echten Daten übertragen und keine echten Zahlungen verarbeitet.

## Eigene Medien

Logo, Bildmarke, Dashboardgrafik, Illustration, Demo-Video und Klangmarke wurden für dieses Projekt erstellt und auf der Urheberrechtsseite dokumentiert.

## Deployment über GitHub Pages

1. Inhalt dieses Ordners in ein öffentliches GitHub Repository hochladen.
2. In `Settings > Pages` die Quelle auf `Deploy from a branch` stellen.
3. Branch `main` und Folder `/ root` auswählen.
4. Den erzeugten GitHub-Pages-Link abgeben.

Wichtig: `index.html` muss direkt im Repository liegen, nicht in einem Unterordner.
