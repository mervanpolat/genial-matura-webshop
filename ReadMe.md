# Genial Matura Webshop

Hier habe ich eine statische HTML/CSS/JavaScript Webseite für die LVA Daten- und Infrormatikrecht entwickelt.

## Projektidee

**Genial Matura** ist eine fiktive interaktive Matura Vorbereitungsplattform. Das Produkt bietet digitale Übungen, Quizfunktionen, Schritt-für-Schritt-Erklärungen, Fortschrittsanzeigen, Matura-Simulationen und Lernpakete für verschiedene Mathematik Maturatypen wie HTL1, HTL2, usw. .

## Unternehmen

- Unternehmensname: Genial Learning e.U.
- Standort: Wien, Österreich
- Mitarbeiter:innen: 5
- Geschäftsmodell: Freemium, Pro-Abo, Einmalverkauf von Matura-Paketen und optionale Schullizenzen

## Umsetzung

Die Website ist statisch umgesetzt. Warenkorb, Checkout, Kontaktformular, Cookie-Einstellungen und Analyseprozesse sind nur simuliert. Es werden keine echten Daten übertragen und keine echten Zahlungen verarbeitet.
